## 🎯 Goal

Make `createActiveHandler` tolerant of a single unreadable/malformed tasknote — one bad file should drop out of the active list, not 500 the whole project.

## ✅ Acceptance

- [x] One malformed/unreadable tasknote no longer rejects the whole `Promise.all`; the valid tasknotes still serialize
- [x] Regression test in `devApi.test.ts` feeds a malformed tasknote alongside a valid one and asserts the valid one survives
- [x] Typecheck + lint + targeted tests pass on the changed files
