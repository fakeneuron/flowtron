**Discovery Notes:**

The two helpers are identical:
```ts
async function safeReaddir(dir: string): Promise<Dirent[]> {
  try {
    return (await readdir(dir, { withFileTypes: true })) as Dirent[];
  } catch {
    return [];
  }
}
```
Both files import `readdir` (from `node:fs/promises`) and `Dirent` (from `node:fs`) for this helper. `archiveCache.ts` uses `readdir` ONLY via `safeReaddir` → both imports become removable there. `devApi.ts` also uses `readFile` from the same import line → keep `readFile`, drop `readdir`; `Dirent` is referenced only in `safeReaddir`'s signature → drop after extraction. Sibling pattern: `originGuard.ts` (standalone helper module + `originGuard.test.ts`).

Discovery surfaced no significant deviation → skip 🛠️.
