# FE-107 | wikilink-markdown-link-fidelity

[← PLAN.md](../PLAN.md) · ✅ Completed · 🔗 [[CORE-232]]

## 🎯 Goal

Keep the visible link text when `WikilinkMarkdown` refuses a non-http(s) href, and stop forwarding react-markdown's `node` prop onto the rendered `<a>`, with tests for both.

## ✅ Acceptance

- [x] A disallowed-href markdown link (`data:` / `blob:` / `javascript:`) renders its text as plain content with no `<a>` element — `npm --prefix viz test -- WikilinkMarkdown`
- [x] An allowed `https://` link's `<a>` carries no `node` attribute and rendering emits no React unknown-prop warning — `npm --prefix viz test -- WikilinkMarkdown`
- [x] Existing allowlist / wikilink tests still pass — `npm --prefix viz test -- WikilinkMarkdown`
- [x] Type-check and lint clean — `npm --prefix viz run typecheck` · `npm --prefix viz run lint`

## 🧩 Subtasks

- [x] In `WikilinkMarkdown.tsx`, destructure `node` out of the `a` component props so `{...props}` no longer carries it
- [x] Replace `if (!isAllowed) return null;` with `return <>{children}</>` (text survives, anchor dropped)
- [x] Extend `WikilinkMarkdown.test.tsx`: disallowed-href tests assert the text is still in the document; new test asserts the allowed `<a>` has no `node` attribute and `console.error` is not called
- [x] Run targeted tests, typecheck, lint

## 🔗 Related
