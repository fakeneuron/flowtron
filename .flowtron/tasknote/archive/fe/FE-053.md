**Discovery Notes:**

Root cause is environmental (Node 26 + jsdom + parallel contention slows userEvent-heavy tests), not a logic bug in the test. The test passes in ~340ms in isolation but the file runs ~26s in full-suite runs, so individual userEvent tests can blow past 5000ms when the CPU is contended.
