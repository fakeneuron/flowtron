# FE-101.2 | archive-wire-slim

[← PLAN.md](../PLAN.md) · 🟢 In progress · 🔗 [[FE-EPIC-101]] · [[FE-101.5]]

## 🎯 Goal

Drop the unconsumed `body` field from the `/api/archive` wire payload so the endpoint stops shipping ~9.4 MB of raw tasknote markdown the UI never reads, keeping the derived `goal` / `acceptance` / `subtasks` / `phases` fields intact.

## ✅ Acceptance

- [x] `Tasknote` (`viz/src/tasknote.ts`) no longer declares `body`; `parseTasknote` keeps it as a function-local only, and every derived field (`goal` / `acceptance` / `subtasks` / `starterContext` / `starterSubsections` / `subtasksProgress` / `phases` / `closureDrift`) is unchanged.
- [x] `/api/archive` and `/api/active` JSON payloads carry no `body` key. Both serve the same `Tasknote` shape — no archive-specific type is forked.
- [x] `viz/src/test/fixtures.ts`'s `makeTasknote` no longer sets `body`; `viz/src/tasknote.test.ts`'s "no YAML block" case asserts on a derived field instead of `tn.body`, keeping its original coverage (content downstream of a missing frontmatter is still scanned).
- [x] Payload reduction measured on flowtron's own archive, before vs. after, and recorded in Testing Notes.
- [x] `npm --prefix viz test`, `npm --prefix viz run typecheck`, and `npm --prefix viz run lint` all clean.

## 🧩 Subtasks

**Discovery Notes:**

**Why the field is safe to drop.** `parseTasknote` (`tasknote-parse.ts:34-57`) computes `body` once and feeds it to every extractor — `extractSection` × 4, `countChecklist` × 4, `extractStarterSubsections`, `extractArchivedDate`, `closureDrift`. All of those results are separate fields on the returned object. `body` itself is then carried along purely as a passenger. Demoting it from a returned field to a function-local changes no derivation.

**Full consumer census** (grep across `viz/src` for `.body`, excluding `document.body` and the unrelated HTTP-response `body` in `originGuard.test.ts`):

| Site | Use | Action |
|---|---|---|
| `tasknote-parse.ts:38,47` | local `const body`, then returned | keep local, drop from return |
| `tasknote.test.ts:602` | `expect(tn.body).toContain('# OLD-1')` | rework onto a derived field |
| `test/fixtures.ts:35` | `body: partial.body ?? ''` default | drop |

Zero UI reads. `TaskDetail.tsx:103`'s `const body` is an unrelated local over `starterSubsections`.

**Blast-radius bound.** `useProjectData.ts:62-73` casts both responses to `Tasknote[]` and merges by `id`; it reads no fields. `taskView.ts` / `utils.ts` read `frontmatter` only. So the type change is compile-time-complete: `tsc --noEmit` will surface every remaining reader.
