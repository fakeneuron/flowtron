## 📏 Pilot rule

**Provenance** is any comment text whose job is to say *which task* or *when* something happened: bare task-ID tags (`(FE-044)`, `FE-087:`, `CORE-333 precedent`) and "before X / began as / is now" history narration. Git history (`git log -S`, `git blame`) already carries it; in code it rots and costs reading time.

**Keep:** the *why* behind the code, stated in present tense; `SPEC …` / `Contract: …` pointers; and task IDs used as **syntax examples**, which must sit inside a backtick code span (`` `FE-310.3a` ``).

**Done-signal (per file, gated):** after stripping backtick code spans, no comment line contains a task-ID token:

```sh
grep -nE '^\s*(//|/\*|\*)' <file> | sed -E 's/`[^`]*`//g' | grep -E '\b[A-Z]{2,}(-EPIC)?-[0-9]+'
```

prints nothing. The comment-line ratio (`grep -cE '^\s*(//|/\*|\*)'` over `wc -l`) is **reported, not gated**. Operator decision 2026-09-22.
