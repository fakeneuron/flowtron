# FE-111 | keyboard-nav-enter-button-guard

[← PLAN.md](../PLAN.md) · ✅ Completed

## 🎯 Goal

Ignore `Enter` in `useKeyboardNav` when the event target is a `BUTTON`/`A` so the hook's global keydown handler doesn't hijack native button/link activation with its own row-expand toggle.

## ✅ Acceptance

- [x] `Enter` fired at a focused `BUTTON` or `A` element is not intercepted (no `preventDefault`, no `setExpandedId`/`toggleEpic` call) — `npm --prefix viz test -- useKeyboardNav`
- [x] `Enter` fired at a non-button/link target (row selection via `selectedId`) still expands/collapses/toggles the epic exactly as before — `npm --prefix viz test -- useKeyboardNav`
- [x] Typecheck passes — `npm --prefix viz run typecheck`

## 🧩 Subtasks

- [x] Add test cases covering the new guard (button/link target no-ops; non-button target unaffected)
- [x] Run targeted tests + typecheck
