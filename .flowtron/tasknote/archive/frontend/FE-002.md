- **Architecture decisions made during execution:**
  - **No SSE per-project filtering.** SSE broadcast stays global; client refetches the active project on any change. Cheap, matches FE-011's pattern, no per-client subscription state. Cost: a change to project X triggers a (no-op) refetch when the user is viewing project Y. Acceptable; refetch is idempotent and cached on the client side via React state diffing.
  - **`activeProjectRef` for SSE handler.** Avoids tearing down + re-creating the EventSource on every project switch (the SSE useEffect deps stay constant via the ref). Switch is filter-reset + state-set + immediate refetch, not a re-subscription.
  - **`safeReaddir` helper.** Two endpoints had inline try/catch around `readdir` returning `[]` on missing dir; extracted once and typed as `Dirent[]` to avoid the `Awaited<ReturnType<typeof readdir>>` overload-mismatch quirk.
  - **`window.scrollTo({ top: 0, behavior: 'auto' })` on switch.** Mirrors fresh-load semantics. `behavior: 'auto'` (instant) over `'smooth'` so the project switch feels like a hard navigation, not a scroll animation.
