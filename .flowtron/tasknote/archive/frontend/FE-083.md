# FE-083 | row-props-context

[← PLAN.md](../PLAN.md) · 🟢 In progress

## 🎯 Goal

Collapse the hand-duplicated 13-prop row-interaction bundle into a single context/object so a new row-level interaction touches one place instead of 4–5 files.

## ✅ Acceptance

- [x] The row-interaction bundle (`tasknotesById`, `expandedId`, `setExpandedId`, `expandedEpicIds`, `toggleEpic`, `highlightId`, `selectedId`, `navigateToTask`) is provided once via a new context in `App.tsx` and consumed via a hook in `PrioritySection`/`EpicRow`/`TaskRow`/`SubtaskRow`/`TaskRowInner` instead of being individually prop-drilled at each layer
- [x] `VisibilityPrefs` is consumable via a `useVisibilityPrefs()` hook (extending the existing `VisibilityContext`) instead of a `visibility` prop drilled through the same chain
- [x] `npm --prefix viz run typecheck`, `npm --prefix viz run lint`, and `npm --prefix viz test` all pass with no behavior change (existing `App.test.tsx` suite, which exercises these rows end-to-end, passes unmodified)
- [x] Adding one new row-level interaction after this change touches the context definition + one consuming component, not 4–5 files (noted in the recap)

## 🧩 Subtasks

- [ ] Add a `useVisibilityPrefs()` hook to `viz/src/ui/VisibilityContext.tsx` returning the full `VisibilityPrefs`; keep `usePalette()` as a derived convenience hook built on top of it
- [ ] Add `viz/src/ui/RowInteractionContext.tsx`: a context + `useRowInteraction()` hook carrying `{ tasknotesById, expandedId, setExpandedId, expandedEpicIds, toggleEpic, highlightId, selectedId, navigateToTask }`
- [ ] Wire the new provider into `App.tsx` (alongside `VisibilityProvider`/`SearchProvider`); drop the 9 now-contextual props from the `<PrioritySection>` (App.tsx:256-271) and `<BoardView>` (App.tsx:419-433) JSX call sites
- [ ] Trim `BoardViewProps`/`PrioritySectionProps` to only their genuinely local props (`sections`/`bySection`/`collapsedSections`/`toggleSection` and `priority`/`nodes`/`collapsed`/`onToggle` respectively); consume the new hooks for the rest
- [ ] Update `EpicRow.tsx`/`TaskRow.tsx`/`SubtaskRow.tsx` to consume `useRowInteraction()`/`useVisibilityPrefs()` instead of receiving the bundle as props; keep only node-specific props (`node`/`task`, `expanded`/`toggleExpanded`); compute `highlightId === task.id` / `selectedId === task.id` internally
- [ ] Update `TaskRowInner.tsx` to pull `tasknotesById`/`rowChips`/`density` from the new hooks instead of props; keep `task`, `isExpandedDetail`, `onToggleDetail`, `extraRightSlot` as props (per-row derived)
- [ ] Run `npm --prefix viz run typecheck`, `npm --prefix viz run lint`, and `npm --prefix viz test` (targeted: `App.test.tsx`, plus the full suite since the change is cross-cutting)
