# FE-034 | empty priority panels

[← PLAN.md](../PLAN.md) · 🟢 In progress

## 🎯 Goal

Hide PrioritySection cards that have zero visible tasks after filtering, and render a subtle muted footer listing the skipped sections by name.

## ✅ Acceptance

- [ ] PrioritySection cards with zero tasks (post-filter) are not rendered in Priority view
- [ ] A muted footer at page bottom lists empty sections: "No tasks in: Critical · Low" (section names joined by ` · `)
- [ ] When all sections are empty, footer collapses to "No tasks in this project"
- [ ] Footer is not shown when no sections are empty
- [ ] Behavior respects current visibility prefs (same filter logic used by PrioritySection)
- [ ] Feature is Priority view only (no change to other views)

## 🧩 Subtasks

- [ ] Add `listViewEmptySections` useMemo in `App.tsx` (filter `SECTIONS` where `bySection[p].length === 0`)
- [ ] In list view JSX, filter `SECTIONS` to non-empty before `.map()` — skip zero-task PrioritySection cards
- [ ] Add muted footer below the sections div: "No tasks in: X · Y" using ` · ` separator
- [ ] Handle all-empty case: collapse footer text to "No tasks in this project"
- [ ] Suppress footer entirely when no sections are empty
