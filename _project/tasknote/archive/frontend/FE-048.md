# FE-048 | viz-per-project-version-display

[← PLAN.md](../PLAN.md) · 🟢 In progress

## 🎯 Goal

Make the viz header show the actual latest flowtron version that a given app has pinned (parsed from its `_project/flowtron/SPEC.md`) instead of always hardcoding the viz tool's own v4.5.0. Also silence the per-file `[archiveCache] ...` warnings for legacy unparsable YAML in adopters' archived tasknotes (per write-once policy), and update the documented `npm --prefix viz ...` / direct `npm run ...` examples so they work whether the shell is at repo root or already `cd`ed inside `viz/`.
