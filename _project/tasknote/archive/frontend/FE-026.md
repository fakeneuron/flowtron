# FE-026 | viz-bundle-code-split

[← PLAN.md](../PLAN.md) · ✅ Completed · 🔗 [[FE-019]]

## 🎯 Goal

Lazy-load `TaskDetail` (mounted only when a row's detail panel is expanded) and split `parseTasknote` into a server-only module so the client bundle no longer pulls `react-markdown`, `remark-gfm`, or `gray-matter` at first paint.

## ✅ Acceptance

- [ ] `parseTasknote` lives in a new server-only module `viz/src/tasknote-parse.ts`; `archiveCache.ts` and `vite.config.ts` import from it.
- [ ] `viz/src/tasknote.ts` no longer imports `gray-matter`; `gray-matter` is absent from the client entry chunk.
- [ ] `TaskDetail` is lazy-loaded via `React.lazy` + `<Suspense>` from `TaskRow.tsx` and `EpicRow.tsx`; `react-markdown` + `remark-gfm` ship in a separate chunk loaded on first row-expand.
- [ ] Initial-paint gzipped JS shrinks by ≥40 KB vs the FE-019 baseline (~124 KB → ≤84 KB), confirmed via `npm run build` per-chunk report.
- [ ] All existing tests pass (`npm test`); `npm run build` (tsc --noEmit + vite build) is green.
- [ ] Manual smoke: expand/collapse a row, navigate via wikilink — works as before.

## 🧩 Subtasks
