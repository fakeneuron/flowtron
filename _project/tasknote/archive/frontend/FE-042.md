# FE-042 | search-match-highlight

[← PLAN.md](../PLAN.md) · 🟢 In progress

## 🎯 Goal

Highlight the matched substring inside rendered `task.id` and `task.description` cells when the search input filters tasks, so users can scan large result sets faster.

## ✅ Acceptance

- [ ] Matched substring highlighted (case-insensitive) in `task.id` in `TaskRowInner` when search is active
- [ ] Matched substring highlighted in description/shortname/title text in `TaskRowInner` when search is active
- [ ] Same highlighting applied to `task.id` and `task.description` in `SubtaskRow`
- [ ] No highlight rendered when search query is empty
- [ ] Tests pass for `splitHighlight` utility
